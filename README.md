# Fate/Apocrypha mod (Forge 1.20.1)

Сборка идёт на GitHub Actions: Java и Gradle у себя ставить не нужно.
Готовый jar: вкладка Actions -> завершённый запуск -> Artifacts -> fate-apocrypha-mod.
Положи jar в папку mods клиента Minecraft Forge 1.20.1 (47.x).

## Сюжет (пока 4 главы)
1. Пролог: создай Катализатор призыва (рецепт: 4 золотых слитка, 4 редстоуна, алмаз в центре).
2. Призыв: ПКМ катализатором по блоку, Астольфо становится твоим Слугой, ты получаешь Командное заклинание.
3. Дорога в Румынию: команда `/fate trifas` переносит в измерение Трифас (и обратно).
4. Тысячелетний замок: заглушка, дальше будет сюжет.

Команды: `/fate story` (текущая цель), `/fate trifas`, `/fate chapter <0-3>` (для операторов, отладка).

## Слуга Астольфо
Следует за Мастером, защищает его, бьёт монстров. Trap of Argalia сбивает врага (перезарядка 20 с).
Командное заклинание (ПКМ по Слуге): лечение + Сила, Сопротивление, Скорость.

## Карта
Измерение Трифас - плоский мир (поверхность на y=-59) для строительства. Как сохранить постройку в мод:
1. Построй здание, поставь рядом Structure Block (команда `/give @s structure_block`), режим Save, задай рамку и имя.
2. Файл появится в `<мир>/generated/minecraft/structures/имя.nbt`.
3. Положи его в `src/main/resources/data/fateapocrypha/structures/`.
Дальше такие структуры можно встроить в генерацию мира или ставить по команде.
