# Fate/Apocrypha mod (Forge 1.20.1)

Сборка идёт на GitHub Actions: Java и Gradle у себя ставить не нужно.
Готовый jar: вкладка Actions -> завершённый запуск -> Artifacts -> fate-apocrypha-mod.
Положи jar в папку mods клиента Minecraft Forge 1.20.1 (47.x).

## Старт
При первом входе в мир игрок получает Командное заклинание и Катализатор призыва.
Потерял заклинание - команда `/fate kit`.

## Призыв
ПКМ катализатором открывает меню выбора Слуги: Астольфо, Могред, Жанна, Семирамида.
У Мастера может быть только один Слуга. Лишние катализаторы можно скрафтить
(золотые слитки по углам, редстоун по бокам, алмаз в центре).

## Командное заклинание (ПКМ - меню)
- Телепортировать Слугу к себе (в пределах одного измерения).
- Усиление Слуги: лечение + Сила II, Сопротивление I, Скорость I на 30 с. Перезарядка 120 с.
- Фантазм (перезарядка 600 с):
  - Астольфо: Trap of Argalia - урон, подброс, замедление и слабость врагам вокруг.
  - Могред: Clarent Blood Arthur - молнии и 30 урона врагам в радиусе 10.
  - Жанна: Luminosite Eternelle - защита, регенерация и поглощение для неё и Мастера.
  - Семирамида: Hanging Gardens of Babylon - иссушение, яд и замедление врагам в радиусе 14.

## Сюжет
1. Пролог: призови Слугу.
2. Дорога в Румынию: `/fate trifas` переносит в измерение Трифас (и обратно).
3. Тысячелетний замок: пока заглушка.

Команды: `/fate story`, `/fate trifas`, `/fate kit`, `/fate chapter <0-2>` (для операторов).

## Скины
`assets/fateapocrypha/textures/entity/*.png`. Тип рук (тонкие/обычные) задаётся в `ClientEvents.java`:
Астольфо и Жанна - тонкие, Могред и Семирамида - обычные.

## Карта
Измерение Трифас - плоский мир (поверхность y=-59) для строительства. Сохранение построек:
1. Построй здание, возьми Structure Block (`/give @s structure_block`), режим Save, задай рамку и имя.
2. Файл появится в `<мир>/generated/minecraft/structures/имя.nbt`.
3. Положи его в `src/main/resources/data/fateapocrypha/structures/`.
