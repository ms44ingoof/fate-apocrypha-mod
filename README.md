# Fate/Apocrypha mod (Forge 1.20.1)

Сборка идёт на GitHub Actions: Java и Gradle у себя ставить не нужно.
Готовый jar: вкладка Actions -> завершённый запуск -> Artifacts -> fate-apocrypha-mod.
Положи jar в папку mods клиента Minecraft Forge 1.20.1 (47.x).

## Что есть
- Катализатор призыва: ПКМ по блоку призывает Астольфо (Rider Чёрных) как твоего Слугу.
- Командное заклинание (3 заряда): ПКМ по своему Слуге - полное лечение + Сила, Сопротивление, Скорость на 30 с.
- Астольфо: следует за Мастером, защищает его, бьёт монстров. Trap of Argalia: удар сбивает врага (перезарядка 20 с).

## Текстуры
- `textures/item/command_seal.png` - красный дракон (есть `command_seal_black.png`, чёрный вариант: переименуй, чтобы использовать).
- `textures/entity/astolfo.png` - скин Астольфо (64x64, формат Alex).
